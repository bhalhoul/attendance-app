# معلومة غبية… ولكن حقيقية! — نظام فيديوهات التحديات القصيرة

مشروع Remotion + FFmpeg لإنتاج فيديوهات عمودية (1080×1920، 30fps، **30 ثانية**) فيها تحدٍّ بصري يشجّع الناس يكتبو الجواب ف الكومنتير ويشاركو الفيديو.

## الحلقات

| الحلقة | العنوان | النوع | النسخة | الجواب |
|---|---|---|---|---|
| ep001 | نتا ولا مراتك… شكون عينو أقوى؟ 😂 | لون | A + B + C | 19 |
| ep002 | عينيك ولا عين النسر؟ 🦅 | لون (متوسط) | C — مواجهة | 11 |
| ep003 | واحد فيهم كيضحك بطريقة مختلفة 🤣 | إيموجي 😂/🤣 | A — صادم | 15 |
| ep004 | الرجال ولا العيالات… شكون كيفرّق الألوان أحسن؟ 🤔 | لون (ساهل) | C — مواجهة | 3 |
| ep005 | حرف واحد فيه نقطة زايدة… فين هو؟ 🔍 | حرف ت/ث | B — زوم | 25 |
| ep006 | مستوى صعيب… واش قدّها؟ 🔥 | لون (صعيب) | A — صادم | 10 |
| ep007 | قرد واحد ماشي بحال صحابو 🙈 | إيموجي 🙈/🙉 | B — زوم | 12 |

الملفات ف `out/`: `<id>-<نسخة>-<اسم>.mp4` + صورة غلاف `-cover.jpg`، و `ep001-comparison.mp4` فيه الثلاث نسخ جنب بعض.
كل حلقة عندها موسيقى خاصة بها (مقام + نغمة + لحن + إيقاع مختلفين).

### النسخ (طريقة الجذب)
- **A — العنوان الصادم (slam)**: العنوان كيتضرب كلمة بكلمة مع الإيقاع + اهتزاز + فلاش
- **B — الشبكة من أول ثانية (zoom)**: الشبكة مزوّمة وضبابية وكتوضح مع جملة تحدي
- **C — المواجهة (versus)**: شاشة مقسومة طرف ضد طرف + VS

## التسلسل الزمني (120 BPM → ضربة كل 15 فريم)

| الوقت | المقطع |
|---|---|
| 0–4 ث | الهوك (يختلف حسب النسخة) |
| 4–6 ث | ظهور الشبكة + التعليمة |
| 6–16 ث | عد تنازلي 10 → 1 (ف النص: جملة تشجيع `midHint`) |
| 16–20 ث | «كتب الرقم ف الكومنتير 👇» قبل الجواب |
| 20–25 ث | كشف الجواب + معلومة حقيقية |
| 25–30 ث | دعوة للمشاركة + اسم السلسلة |

كل التوقيت ف `shared/timing.js` — الموسيقى (`scripts/generate-audio.mjs`) والصورة كيقراو منو بجوج، إلا بدلتي شي حاجة كتبقى متزامنة.

## الأوامر

```bash
npm install
npm run studio                       # معاينة وتعديل مباشر ف Remotion Studio
npm run render -- --all              # كل الحلقات بالنسخة ديال كل وحدة → out/
npm run render -- --id ep001         # A + B + C + فيديو المقارنة
npm run render -- --id ep002 --variant B   # حلقة ب نسخة معينة
npm run render -- --safe 1           # نسخ مراجعة فيها مناطق أزرار TikTok/Instagram
npm run stills -- --variant A --frames 0,100,380 --safe 1
npm run validate                     # التحقق من كل الحلقات
npm run new-challenge -- --id ep008 --seed 42 --difficulty medium --variant C --title "..."
npm run new-challenge -- --id ep009 --type symbol --base 😂 --odd 🤣 --variant A
npm run new-challenge -- --id ep010 --type symbol --base ب --odd ن --font arabic
```

> إلا ما كانش Chrome عندك، Remotion كيحمّل واحد بوحدو. ويمكن تحدد واحد عندك بـ `REMOTION_BROWSER=/path/to/chrome-headless-shell`.

## نظام التحديات

- **نوعين ديال التحديات**: `color` (مربع لونو مختلف) و `symbol` (إيموجي ولا حرف مختلف، نفس لون الخلفية لكل المربعات).
- **البيانات**: كل حلقة عندها ملف `challenges/<id>.json` فيه النوع، والنسخة، والألوان/الرموز، والجواب (`answer`)، والبذرة (`seed`)، والموسيقى (`music`)، وكل النصوص بالدارجة. أي نص بدلتيه هنا كيتبدل ف الفيديو.
- **التوليد التلقائي**: `new-challenge` كيختار لون أساسي ويحسب اللون المختلف حتى يوصل للفرق المطلوب، ومن بعد كيختار موضع الجواب عشوائياً بلا ما يعاود نفس الرقم ديال آخر 3 حلقات. نفس البذرة كتعطي ديما نفس التحدي.
- **العدالة**: الفرق كيتقاس بـ ΔE2000 (كيف كتشوفو العين)، وكيكون فالإضاءة أساساً، باش يبقى واضح حتى للناس اللي عندهم عمى الألوان.
  - `easy` 14–18 · `medium` 10–13 · `hard` 8–10
  - الفيديو ما كيتصيّرش إلا كان الفرق تحت 8 (شبه مستحيل) ولا فوق 25 (ساهل بزاف).
- ما كاين حتى تأثير ضوئي فوق المربعات (لا تدرج ولا لمعة على مربع واحد)، وخلفية الشبكة رمادية محايدة. النبضة كتطبّق على الشبكة كاملة، يعني ما كاين حتى تضليل.

## المناطق الآمنة

`shared/safe-zones.js`: المنطقة الآمنة هي تقاطع منطقتي TikTok و Instagram Reels (x: 90→910، y: 250→1460). كل النصوص والشبكة كيبقاو داخلها، بعيد على عمود الأزرار على اليمين وعلى الوصف لتحت. تقدر تشوفها بـ `--safe 1`.

## الصوت

الموسيقى والمؤثرات كيتولدو برمجياً، يعني بلا حتى ملف خارجي ولا مشاكل حقوق: دربوكة (دوم/تك)، وباص، ونقر وتري بمقام الحجاز، وwhoosh، وtick للعد، وriser قبل الكشف، وimpact + ding فلحظة الجواب. ما كاين حتى تعليق صوتي. FFmpeg كيوحّد الصوت على −14 LUFS (معيار TikTok/Reels).

## الهيكل

```
challenges/        بيانات الحلقات (الجواب هنا)
shared/            التوقيت، المناطق الآمنة، الألوان، توليد/تحقق التحدي
src/               مكونات Remotion (Grid, Countdown, AnimatedText, hooks/…)
scripts/           توليد الصوت، التصيير، اللقطات، حلقة جديدة
public/audio/      الصوت المولّد
out/               ملفات MP4 النهائية
```

## نشرة الأخبار (60 ثانية)

قالب منفصل ف نفس المشروع: `src/news/NewsVideo.tsx` + بيانات اليوم ف `news/<التاريخ>.json`.

- 0–4 ث مقدمة · 6 أخبار × 8.5 ث · 5 ث خاتمة (سؤال للكومنتير + دعوة للمشاركة)
- كل خبر: إيموجي + تصنيف + عنوان + جوج تفاصيل + **المصدر**، شريط تقدم بحال الستوريات، وشريط أخبار متحرك داخل المنطقة الآمنة
- موسيقى إخبارية (مقام نهاوند) + مؤثرات، بلا تعليق صوتي: `scripts/generate-news-audio.mjs`

```bash
cp news/2026-11-22.json news/2026-11-23.json   # بدّل id و dateLabel والأخبار والمصادر
npm run render:news -- --date 2026-11-23       # → out/news-2026-11-23.mp4
```

> الأخبار كتتكتب يدوياً من مصادر موثوقة — السكريبت كيرفض أي خبر بلا `source`.
