# معلومة غبية… ولكن حقيقية! — نظام فيديوهات التحديات القصيرة

مشروع Remotion + FFmpeg لإنتاج فيديوهات عمودية (1080×1920، 30fps، 18 ثانية) فيها تحدٍّ بصري يشجّع الناس يكتبو الجواب ف الكومنتير ويشاركو الفيديو.

## الحلقة 1: «نتا ولا مراتك… شكون عينو أقوى؟ 😂»

| الملف | الوصف |
|---|---|
| `out/ep001-A-slam.mp4` | **A — العنوان الصادم**: العنوان كيتضرب كلمة بكلمة مع الإيقاع + اهتزاز + فلاش |
| `out/ep001-B-zoom.mp4` | **B — الشبكة من أول ثانية**: الشبكة مزوّمة وضبابية، كتوضح مع "عندك 5 ثواني…" |
| `out/ep001-C-versus.mp4` | **C — المواجهة**: شاشة مقسومة «نتا 👨» ضد «مراتك 👩» + VS |
| `out/ep001-comparison.mp4` | الثلاث نسخ جنب بعض للمقارنة |
| `out/*-cover.jpg` | صورة غلاف من كل نسخة |

التحدي نفسه فالثلاث نسخ: الجواب **19**، اللون الأساسي `#29ae89`، اللون المختلف `#5edebb`، والفرق ΔE2000 = 12.92.

## التسلسل الزمني (120 BPM → ضربة كل 15 فريم)

| الوقت | المقطع |
|---|---|
| 0–3 ث | الهوك (يختلف حسب النسخة) |
| 3–4 ث | ظهور الشبكة بموجة قطرية + التعليمة |
| 4–9 ث | عد تنازلي 5 → 1 (كل رقم على ضربة) |
| 9–12 ث | «كتب الرقم ف الكومنتير 👇» قبل الجواب |
| 12–15 ث | كشف الجواب + معلومة |
| 15–18 ث | دعوة للمشاركة مع الزوج/الزوجة/صاحب + اسم السلسلة |

كل التوقيت كاين ف `shared/timing.js`. الموسيقى (`scripts/generate-audio.mjs`) والصورة كيقراو منه بجوج، لذلك الحركات كتبقى على الإيقاع إلا بدلتي شي حاجة.

## الأوامر

```bash
npm install
npm run studio                       # معاينة وتعديل مباشر ف Remotion Studio
npm run render                       # A + B + C + فيديو المقارنة → out/
npm run render -- --variant B        # نسخة وحدة
npm run render -- --safe 1           # نسخ مراجعة فيها مناطق أزرار TikTok/Instagram
npm run stills -- --variant A --frames 0,100,380 --safe 1
npm run validate                     # التحقق من كل الحلقات
npm run new-challenge -- --id ep002 --seed 42 --difficulty medium --title "..."
```

> إلا ما كانش Chrome عندك، Remotion كيحمّل واحد بوحدو. ويمكن تحدد واحد عندك بـ `REMOTION_BROWSER=/path/to/chrome-headless-shell`.

## نظام التحديات

- **البيانات**: كل حلقة عندها ملف `challenges/<id>.json` فيه الألوان، والجواب (`answer`)، والبذرة (`seed`)، والصعوبة، وكل النصوص بالدارجة. أي نص بدلتيه هنا كيتبدل ف الفيديو.
- **التوليد التلقائي**: `new-challenge` كيختار لون أساسي ويحسب اللون المختلف حتى يوصل للفرق المطلوب، ومن بعد كيختار موضع الجواب عشوائياً بلا ما يعاود نفس الرقم ديال آخر 3 حلقات. نفس البذرة كتعطي ديما نفس التحدي.
- **العدالة**: الفرق كيتقاس بـ ΔE2000 (كيف كتشوفو العين)، وكيكون فالإضاءة أساساً، باش يبقى واضح حتى للناس اللي عندهم عمى الألوان.
  - `easy` 14–18 · `medium` 10–13 · `hard` 8–10
  - الفيديو ما كيتصيّرش إلا كان الفرق تحت 8 (شبه مستحيل) ولا فوق 25 (ساهل بزاف).
- ما كاين حتى تأثير ضوئي فوق المربعات (لا تدرج ولا لمعة على مربع واحد)، وخلفية الشبكة رمادية محايدة. النبضة كتطبّق على الشبكة كاملة، يعني ما كاين حتى تضليل.

## المناطق الآمنة

`shared/safe-zones.js`: المنطقة الآمنة هي تقاطع منطقتي TikTok و Instagram Reels (x: 90→910، y: 250→1460). كل النصوص والشبكة كيبقاو داخلها، بعيد على عمود الأزرار على اليمين وعلى الوصف لتحت. تقدر تشوفها بـ `--safe 1`.

## الصوت

الموسيقى والمؤثرات كيتولدو برمجياً، يعني بلا حتى ملف خارجي ولا مشاكل حقوق: دربوكة (دوم/تك)، وباص، ونقر وتري بمقام الحجاز، وwhoosh، وtick للعد، وriser قبل الكشف، وimpact + ding فلحظة الجواب. ما كاين حتى تعليق صوتي. FFmpeg كيوحّد الصوت على −14 LUFS (معيار TikTok/Reels).

## الهيكل

```
challenges/        بيانات الحلقات (الجواب هنا)
shared/            التوقيت، المناطق الآمنة، الألوان، توليد/تحقق التحدي
src/               مكونات Remotion (Grid, Countdown, AnimatedText, hooks/…)
scripts/           توليد الصوت، التصيير، اللقطات، حلقة جديدة
public/audio/      الصوت المولّد
out/               ملفات MP4 النهائية
```
