# QRVE Digital Agency — وثيقة المرحلة الأولى (معتمدة مبدئياً)

> احفظ هذا الملف في: `C:\QRVE\qrve-agency\docs\QRVE_PHASE1.md`
> هو المرجع الذي يقرأه Claude Code المحلي قبل بدء المرحلة الثانية.

## 1. القرارات المعتمدة من المالك

1. التشغيل على جهاز Windows الخاص بالمالك عبر Claude Code المحلي، وليس في حاوية سحابية.
2. مدير تنفيذي رئيسي (الجلسة الرئيسية) + خمسة وكلاء متخصصين. قسم البرمجة يُضاف لاحقاً.
3. الهدف شركة افتراضية تنفذ مهام وتنتج ملفات فعلية، وليس CRM تقليدياً فقط.
4. لكل وكيل: دور واضح، أدوات وصلاحيات محددة، مهام قابلة للتنفيذ، سجل تشغيل حقيقي، نتائج قابلة للفحص، حالة تظهر في لوحة التحكم.
5. الأسعار: البطاقة العادية 15€، البطاقة المخصصة 20€. **لم يُحدَّد بعد** إن كانت شاملة للضريبة (سبتة تطبق IPSI لا IVA). لا يُفترض أي شيء.
6. البدء بعروض الأسعار (Presupuestos) وإدارة المستحقات. الفواتير الضريبية الرسمية مؤجلة حتى التحقق القانوني (ومنها VeriFactu).
7. البحث عن العملاء المحتملين في سبتة مسموح من مصادر تجارية عامة مسموحة، مع حفظ رابط المصدر لكل معلومة. **ممنوع التواصل معهم دون موافقة المالك.**
8. استخدام هوية QRVE الحالية إن توفرت ملفاتها في `brand/`. لا هوية بديلة دون موافقة.
9. بيانات العملاء والمشاريع محلية وخارج Git. GitHub للشيفرة والقوالب والملفات غير الحساسة فقط.
10. لوحة تحكم مرئية مستقبلاً (المرحلة الخامسة).
11. لا محاكاة وهمية. كل حالة مرتبطة بتنفيذ حقيقي مسجل.
12. الشركة تطور نفسها تدريجياً، وأي تغيير جوهري في الهيكلة أو الصلاحيات يحتاج موافقة المالك.

## 4. نظام البيانات (المرحلة الثالثة — لا يُبنى قبل نجاح اختبار الوكلاء)

SQLite محلي (`data\qrve.db`) يُكتب فيه فقط عبر أداة `qrve` بلغة Python تفرض القواعد.
الجداول: clients, projects, status_history, interactions, quotes, payments (الإثبات إلزامي), expenses, leads (رابط المصدر إلزامي), tasks, agent_runs.
الحالات: Lead → Contacted → Negotiation → Approved → In Progress → Review → Delivered → Paid، إضافة إلى Cancelled وOn Hold. `Delivered` لا تعني `Paid`.

## 6. قواعد ثابتة

- لا حذف ملفات دون موافقة. لا تعديل لمواقع حية. لا إرسال رسائل أو عروض دون موافقة.
- لا عمليات مالية. لا اختلاق عملاء أو مبيعات أو مدفوعات.
- لا رفع بيانات العملاء لخدمات خارجية دون إذن.
- لا خلط مع مشروع غرفة الأخبار.
- التقارير الإدارية بالعربية، والمراسلات للعملاء بالإسبانية.
